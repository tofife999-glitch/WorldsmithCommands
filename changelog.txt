Worldsmith Commands - changelog

1.1.0 (2026-10-20)
- New planning commands: findplanet (search the sector with filters), planetinfo (everything about one
  planet), startypes (list all star types).
- New building commands: addmoon, addobject (stable location, relay, buoy, sensor array, inactive gate),
  addring (asteroid belt, dust/ice ring, magnetic field), newsystem (empty star system in hyperspace).
- New editing commands: moveplanet, resizeplanet, changestar (optionally rerolls planet conditions).
- New faction commands: factionpower (report, 'clear' ends Worldsmith effects), strengthenfaction and
  weakenfaction with levels 1-3. All faction effects are gradual and wear off by themselves; level 3 lasts
  up to 3 years.
- popcap now replaces a Worldsmith growth freeze on that colony.

1.0.1 (2026-10-19)
- rename: fixed an error after renaming a planet in systems without autogenerated hyperspace jump points
  (the planet was renamed, but an error was printed instead of the confirmation).
- rename: the '>' is now optional. Type the current name and then the new name (rename Glith_I Hakeball),
  or with a planet's dialog open just the new name (rename Hakeball). Clearer help when it's unclear.
- removeplanet: decorative orbital debris (vanilla "Habitat" junk around planets with ruins) no longer blocks
  removing a planet; it is removed together with the planet. Other blockers are grouped (e.g. "3x object X").
- showsystem: works in systems without a center object.

1.0.0 (2026-10-19)
- First release for Starsector 0.98a-RC8.
- Commands: showsystem, visit, npccolony, treatasnpccolony, popcap, planettypes, terraform, rename,
  addplanet, removeplanet, npcexpedition.
- Tab completion for planet, station, system and faction names, planet types and keywords.
- Yes/Cancel confirmation popups (or type the command again with 'yes').
- Save-safe utility mod: adds nothing of its own to the save.
