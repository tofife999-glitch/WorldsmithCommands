Worldsmith Commands - changelog

1.1.0 (2026-10-20)
- IMPORTANT: no longer a utility mod. It now ships 8 blank faction slots for spawnfaction, which become part
  of every save it runs in, so it can be added to a running save but not removed from one.
- Removed npccolony, npcexpedition and addobject: Additional Console Commands does the same
  (colonizeplanet, spawncolonyfleet, addentity).
- New faction commands: spawnfaction (a new faction with its own name, random player flag, ships and
  tactics copied from an existing faction, empty lore and 1-5 colonies, here or at a random place; set up
  in a popup; Nexerelin runs it like any other faction), factionflag (change any faction's flag),
  factionlore (rewrite any faction's lore on its Intel page), rename faction.
- New war commands: wars (who fights whom, alliances, war weariness), totalwar, totalpeace.
- New apocalypse command: remnant (Remnant armadas raid every inhabited system), bombard (every colony
  saturation-bombed into ruins), revolution (rebellions in every colony). Your colonies are spared unless
  you add 'all'.
- New star and space commands: addstar (binary/trinary systems), recolor (tint planets and stars),
  hyperclouds (clear or grow hyperspace clouds). newsystem and changestar now also make black holes and
  neutron stars, with their event horizon or pulsar beam; removeplanet removes companion stars.
- New planning commands: findplanet (search the sector with filters), planetinfo (everything about one
  planet), startypes (list all star types).
- New building commands: addmoon, addring (asteroid belt, dust/ice ring, magnetic field), newsystem (empty
  star system in hyperspace).
- New editing commands: moveplanet, resizeplanet, changestar (optionally rerolls planet conditions).
- New faction commands: factionpower (report, 'clear' ends Worldsmith effects), strengthenfaction and
  weakenfaction with levels 1-3. All faction effects are gradual and wear off by themselves; level 3 lasts
  up to 3 years.
- New removal commands: removeobject, removering, removemoon (same as removeplanet).
- New wshelp command: plain-language help for filters, conditions, objects, rings, sizes, renaming,
  removing, new systems, stars, hyperspace, factions, new factions, war and the apocalypse.
- newsystem asks whether to generate planets, moons, rings and stable locations or keep the system empty
  ('full' / 'empty' answer it in advance); the new star is named '<name> Prime'.
- rename system <name> <new name> and rename star <name> <new name>.
- changestar accepts the system or star name and the star type in any order, with clearer messages.
- resizeplanet accepts percentages (200% = twice as wide).
- popcap now replaces a Worldsmith growth freeze on that colony.

1.0.1 (2026-10-19)
- rename: fixed an error after renaming a planet in systems without autogenerated hyperspace jump points
  (the planet was renamed, but an error was printed instead of the confirmation).
- rename: the '>' is now optional. Type the current name and then the new name (rename Glith_I Hakeball),
  or with a planet's dialog open just the new name (rename Hakeball). Clearer help when it's unclear.
- removeplanet: decorative orbital debris (vanilla "Habitat" junk around planets with ruins) no longer blocks
  removing a planet; it is removed together with the planet. Other blockers are grouped (e.g. "3x object X").
- showsystem: works in systems without a center object.

1.0.0 (2026-10-19)
- First release for Starsector 0.98a-RC8.
- Commands: showsystem, visit, npccolony, treatasnpccolony, popcap, planettypes, terraform, rename,
  addplanet, removeplanet, npcexpedition.
- Tab completion for planet, station, system and faction names, planet types and keywords.
- Yes/Cancel confirmation popups (or type the command again with 'yes').
- Save-safe utility mod: adds nothing of its own to the save.
